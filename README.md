# DEMON OPS 🎯

شوتر سه‌بعدی اول‌شخص آفلاین برای اندروید با HUD به سبک شوترهای موبایلی — پروژه‌ی مستقل (بدون وابستگی به Demon Games Config).

- موتور: Three.js داخل WebView (کاملاً آفلاین داخل assets)
- نقشه: آرنای صناعی ۶۴×۶۴ با کانتینر و جعبه
- سلاح‌ها: AR-9 (رگبار) + SR-50 (اسنایپر با اسکوپ)
- دشمن: ۴ بات متحرک با AI و ری‌اسپاون
- HUD: مینی‌مپ با هایلایت قرمز دشمن، تایمر، امتیاز، کیل‌فید، هیت‌مارکر، HP/آرمور
- برنده: اولین ۲۰ کشتار یا امتیاز بالاتر در پایان ۵ دقیقه

Build: push به main → GitHub Actions → Release با APK امضاشده.
